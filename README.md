# Meu Gravador 🎙

App React Native (Expo) de notas de voz com `expo-av`.

## Recursos
- Gravar e reproduzir áudio (expo-av)
- Lista com FlatList, nome, barra de progresso e timer
- Persistência com AsyncStorage (nome, uri e duração) + exclusão pelo ícone 🗑
- `useEffect` que para o áudio ao sair do app
- Splash Screen configurada no `app.json`

## Rodar
```
npm install
npx expo start
```
Teste no emulador/celular.
